When should it run?

The earliest time the task may start. It waits in state SCHEDULED until then, and only joins the queue once that time passes — a worker may pick it up any time after. Times are read in your browser's timezone. The REST API also accepts a relative duration (10m), an RFC3339 timestamp, or unix seconds for this field.

Five space-separated fields — minute, hour, day-of-month, month, day-of-week. Example: 0 14 * * 2 runs at 2:00 PM every Tuesday. The submitted task becomes a RECURRING template that never runs itself; it spawns a fresh child run at every fire time.
